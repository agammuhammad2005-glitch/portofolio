# Portfolio Agam (Minimalist Clean)

Landing page personal portofolio yang bersih, modern, dan profesional untuk Agam (Pelajar / Mahasiswa / Fresh Graduate).

## Fitur Halaman
- **Hero Section**: Profil singkat, headline menarik, status aktif ("Terbuka untuk peluang baru").
- **Tentang Saya**: Penjelasan latar belakang diri, motivasi, dan ringkasan keunggulan.
- **Pendidikan & Pengalaman**: Timeline studi, organisasi, atau proyek kampus.
- **Keahlian & Tools**: Kartu kategori keahlian (Web/Frontend, Backend/Code, Tools).
- **Proyek Pilihan**: Showcase 3 contoh proyek dengan deskripsi rapi dan tag teknologi.
- **Kontak**: Tautan email langsung, LinkedIn, dan media sosial.

## Cara Melihat & Menjalankan di Browser
Cukup klik dua kali (double click) file `index.html` di File Explorer, atau jalankan perintah berikut di PowerShell:

```powershell
Start-Process "C:\Users\Agam\.gemini\antigravity\scratch\portfolio-agam\index.html"
```

## Cara Menyesuaikan Konten
Buka file `index.html` lalu edit:
1. **Nama & Bio**: Ubah teks "Agam" dan deskripsi sesuai profil aslimu.
2. **Email & LinkedIn**: Ganti `agam@example.com` dan tautan LinkedIn/GitHub dengan URL akunmu.
3. **Pendidikan & Proyek**: Sesuaikan nama kampus, nama proyek, dan deskripsi sesuai portofoliomu.
